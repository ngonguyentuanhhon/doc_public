4. AI IDE vs AI CLI khác nhau ở đâu?

💻 AI IDE

Triết lý: AI là một phần của IDE.

  • ✅ IDE hoàn chỉnh, giao diện trực quan.
  • ✅ Nhiều tính năng được tích hợp sẵn.
  • ✅ Trải nghiệm liền mạch trong quá trình coding.
  • ⚠️ Thay thế IDE truyền thống (cần làm quen).

⌨️ AI CLI

Triết lý: AI độc lập ở bất kỳ đâu có Terminal.

  • ✅ Nhỏ gọn, tối giản, cực kỳ linh hoạt.
  • ✅ Không phụ thuộc & kết hợp được mọi IDE.
  • ✅ Dễ mở nhiều phiên làm việc song song.
  • ✅ Phù hợp hoàn hảo với automation workflow.
Kết luận: Chúng không thay thế mà bổ trợ cho nhau, tùy vào thói quen và bài toán.

7. Ví dụ thực tế

Task Thêm API cập nhật Avatar cho User

Sử dụng công cụ Antigravity CLI để thực hiện toàn bộ quy trình.

⬇ Bấm mũi tên xuống để xem từng bước

Bước 1: Đưa Requirement

1/5
dev@vtcedu: ~/projects/api-backend
dev@vtcedu:~$ ag-cli task start "Thêm API cập nhật Avatar cho User" --context "Laravel 12, Repository Pattern, Service Pattern, Resource, Module User, MinIO Storage"

# Developer cung cấp thêm rules:
> - Theo đúng Coding Convention dự án
> - Chỉ cập nhật Avatar, không ảnh hưởng field khác.
> - Không làm hỏng các API đang có.

✔ Context loaded. Parsing requirements...

Bước 2: Yêu cầu AI Phân tích

2/5
ag-cli - Analysis Agent
ag-cli> analyze --output=plan

📋 IMPLEMENTATION PLAN:
1. API Contract: POST /api/users/avatar (multipart/form-data)
2. Validation: mimes:jpeg,png,jpg,webp | max:2048
3. Storage Flow: Xóa avatar cũ trên MinIO (nếu có) -> Upload file mới -> Lấy URL.
4. Database: Cập nhật cột `avatar_url` thông qua UserRepository.
5. Module ảnh hưởng: UserController, UserService, UserRepository, UserResource.

⚠️ Risk identified: Cần xử lý rollback Storage nếu DB transaction fail.

Bước 3: Developer Review Plan

3/5

🧑‍💻 Developer chốt phương án:

  • Kiểm tra kĩ Storage Flow & Exception handling.
  • Đảm bảo URL trả về đúng format CDN.
  • Đồng ý với cấu trúc các file bị thay đổi.
ag-cli - Interactive
Do you approve this implementation plan? [Y/n] Y

Any additional instructions? Nhớ catch Exception khi MinIO sập và throw custom ApiError.

✔ Plan approved. Ready for coding phase.

Bước 4: AI Coding

4/5
ag-cli - Coding Agent
ag-cli> execute plan

⚙️ Generating code...
📝 Updated app/Http/Controllers/UserController.php
📝 Updated app/Services/UserService.php (Added transaction & rollback)
📝 Updated app/Repositories/UserRepository.php
✨ Created app/Http/Requests/UpdateAvatarRequest.php

✔ All files written successfully.
Yêu cầu AI: Follow đúng Plan. Không sửa ngoài phạm vi Task.

Bước 5: Developer Review & Merge

5/5

🔍 Dev Review Checklist:

  • ✅ Business Logic đúng chưa?
  • ✅ Validation chặt chưa?
  • ✅ Security (có check quyền user không?)
  • ✅ Xử lý Exception tốt chưa?
  • ✅ Coding Convention của team.

8. Kinh nghiệm xương máu

🎯 Context > Prompt

Đừng chỉ ra lệnh, hãy cung cấp bối cảnh:

  • Requirement rõ ràng
  • Architecture đang dùng
  • Coding Convention
  • Business Rules & Constraints

🛑 Review Plan trước khi Code

Không bao giờ yêu cầu AI viết code ngay lập tức. Hãy bắt nó lên kế hoạch và phân tích trước.

🧠 Kiểm soát Business Logic

AI chỉ hỗ trợ gen code & gợi ý. Developer mới là người quyết định luồng logic cuối cùng.

🔒 Bảo mật thông tin

Tuyệt đối không đẩy cho AI:

.env Passwords API Keys Private Keys Production DB
Không Merge code sinh bởi AI nếu bạn chưa Review từng dòng! AI có thể sai, nhưng Developer chịu trách nhiệm cuối cùng.
